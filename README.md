# Буквоед

Игра в слова из фишек с русскими буквами для 2–3 игроков. Поле 15×15, игра по ссылке без регистрации, есть вкладка с правилами.

Вся игра — один файл `index.html`. Сервер не нужен: браузеры игроков соединяются напрямую через бесплатный сервис [PeerJS](https://peerjs.com).

## Как выложить на GitHub Pages

1. Войдите на [github.com](https://github.com) и нажмите **New repository** (зелёная кнопка или «+» вверху справа).
2. Назовите репозиторий, например `bukvoed`, выберите **Public** и нажмите **Create repository**.
3. На странице нового репозитория нажмите ссылку **uploading an existing file**, перетащите `index.html` и `README.md`, затем нажмите **Commit changes**.
4. Откройте **Settings → Pages**. В блоке **Build and deployment** выберите **Source: Deploy from a branch**, ветку **main** и папку **/(root)**, затем нажмите **Save**.
5. Через 1–2 минуты игра будет доступна по адресу `https://<ваш-логин>.github.io/bukvoed/`.

## Как играть

1. Откройте адрес игры, введите имя и нажмите «Создать стол». Вы станете хозяином стола.
2. Скопируйте ссылку стола и отправьте её друзьям.
3. Друзья открывают ссылку, вводят имя и нажимают «Сесть за стол».
4. Нажмите «Начать партию».

Хозяину нельзя закрывать вкладку, пока идёт партия. Если вкладка закрылась, откройте ту же ссылку в том же браузере: партия продолжится, а друзья переподключатся сами.

Если соединение не устанавливается, скорее всего, сеть блокирует прямые соединения. Попробуйте другой Wi-Fi или мобильный интернет.
